# 平台用例快照

> Kiwi TCMS 策展用例的导出留痕，用于跨时间对账与台账取证

## 1. 生成方式

```bash
cd bms && set -a && . ./deploy/.env && set +a    # 取 MJBK_IP / MJBK_SSH_USER
cd ../test && python3 scripts/kiwi/export_cases.py --out exports/<日期>_策展用例快照.json
```

只读操作（脚本内部按 `product` 查询后打印 JSON），不改平台数据。

## 2. 口径

- **只含策展产品** `BMS 基础管理系统`：CI 导入的 `BMS 自动化用例（CI）` 产品是执行记录、数量大且编号连片，不进快照（对账时如需按编号判定产品，另行查询）。
- 字段：`case_id` / `summary` / `category` / `priority` / `status` / `is_automated` / `tags`——**不含用例正文**（正文在平台，需要时用平台网页查或临时导出）。
- 命名 `<日期>_策展用例快照.json`（快照按日期留存，不覆盖）；需要时另写 `<日期>_对账.md` 记录差异与结论。
- **临时转储**（大范围导出、试验性查询）写 `test/temp/`（已 gitignore），入库的只有本目录。
- 台账与对账结论记在《[Kiwi 用例台账](../../../test文档/用例/Kiwi用例台账.md)》，本目录只存原始快照。
