# 测试侧脚本

> 本目录与 `test文档/` 并排，承载**不被 CI 依赖**的测试工具

## 1. 边界

**放这里**：人工执行或按需调用的测试资产类脚本（Kiwi 用例维护、压测场景、测试数据生成）。

**不放这里**：被流水线直接调用的脚本（`check-base.py`、`check-status.py`、`defect/*`、`governance/*`）——
它们留在 `bms/scripts/tools/`，原因见《[资产总览](../test文档/资产总览.md)》第 3 节「迁移边界」。

## 2. 子目录

| 目录 | 用途 | 说明 |
| --- | --- | --- |
| `kiwi/` | Kiwi 用例登记 / 批量维护 / 导出核对 | 详见 `kiwi/README.md` |
| `perf/` | 压测场景（`scenario_场景.py`） | 详见 `perf/README.md` |
| `data/` | 测试数据生成与环境准备 | 详见 `data/README.md` |

## 3. 通用约定

- 中文输出与中文注释（用户是中国人；提交信息 `type(scope): 中文描述`）。
- 凭据一律从本机 `deploy/.env` 或环境变量读取，**不硬编码、不入库**。
- 脚本须可重复执行（幂等）；破坏性操作必须带确认或 `--dry-run`。
- 每个脚本目录放 `README.md` 说明用法与前置。

> 依《文档生成规范》编写 · 测试资产仓库
