# 测试记录模板

> 任务级测试记录（`测试/NN_测试_xx.md`）的结构骨架与字段口径 · 与《[用例模板](../用例/用例模板.md)》《[Kiwi 用例台账](../用例/Kiwi用例台账.md)》配套

## 1. 用途与落点 <a id="purpose"></a>

- **记录属项目文档，不入本仓**：落点 `bms文档/项目/<阶段>/任务/<域>/<子任务>/测试/NN_测试_<任务>.md`（《[测试规范](../../bms文档/规范/测试规范.md)》「测试资产落点与组织」节：测试记录与报告 → 项目文档）。本仓只承载**模板**。
- 一份任务一份记录；阶段末汇总进 `项目/<阶段>/NN_测试报告_<阶段>.md`（见《[阶段测试报告模板](阶段测试报告模板.md)》）。
- 测试方法口径（分层、命名、覆盖率、缺陷流程）以《测试规范》为准，本模板不重复；此处只固化**结构**与**易漏字段**。

## 3. 字段口径与常见坑 <a id="fields"></a>

| 字段 | 口径 | 常见坑 |
| --- | --- | --- |
| Kiwi 用例 | 只写**平台回读**的编号（`register_cases.py` 输出 `case_id`）；双端 / 双轨分开列 | 按「上一号 + 1」推算——编号跨产品全局自增，必跳号 |
| 用例（函数 / describe） | 后端写测试函数名，前端写 `describe` 名；一编号多断言时列一条代表 | 同一编号在多文件复用时，只列出**主要**承载文件 |
| 执行记录 | 贴**原始输出**（用例数、跳过数、覆盖率终值），不写「已通过」了事 | 只贴成功片段、省略跳过与告警 |
| 覆盖率 | 写清「新增 / 改动文件」与「全量快照」两个口径 | 用全量数字掩盖新增模块未覆盖 |
| 问题与处置 | 「原因」列写根因（不是现象复述）；「落点」列写具体文件或用例 | 只记现象、不记落点，后续无法复现 |
| 偏差与遗留 | 每条**必须有去向**：归口任务 / 阶段编号，或「已闭环（时间 + 落点）」 | 写「后续处理」而不写归口，等于没闭环 |

## 4. 填写检查清单 <a id="checklist"></a>

- □ 六节齐全（测试信息 / 范围与用例 / 执行记录 / 问题与处置 / 覆盖率 / 偏差与遗留）
- □ Kiwi 编号与平台一致（回读核对），代码标记与记录逐号对得上
- □ 执行命令可直接复制重跑，输出含用例数与覆盖率终值
- □ 覆盖率写明新增文件口径与全量口径，未覆盖分支有说明
- □ 偏差与遗留逐条有去向（任务 / 阶段编号或「已闭环」）
- □ 提交前跑 `check-links`（相对链接层级是高频错误点）
