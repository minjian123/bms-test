# 测试文档首页

> 测试资产导航 · 与平台/产品仓库平级的独立仓库

## 1. 本仓范围

本仓承载**测试资产**，[README](../README.md) 说明仓库定位与软链机制。
测试方法本身（分层、命名、覆盖率、缺陷流程等）是平台规范，见
《[测试规范](../bms文档/规范/测试规范.md)》——**本仓不重复定义方法，只承载资产与工具**。

| 你要找什么 | 去哪里 |
| --- | --- |
| 测试方法 / 准入准出 / 缺陷流程 | 平台《[测试规范](../bms文档/规范/测试规范.md)》、平台《[架构设计 · 测试与质量](../bms文档/设计/架构设计/32_架构设计_测试与质量.md)》 |
| 测试资产放在哪（权威边界表） | 本仓《[资产总览](资产总览.md)》 |
| 写用例要填什么 | 本仓《[用例模板](用例/用例模板.md)》 |
| 探索性测试怎么记 | 本仓《[探索性测试记录模板](用例/探索性测试记录模板.md)》 |
| Kiwi 用例登记 / 维护脚本 | 本仓 `scripts/kiwi/` |
| 压测场景 | 本仓 `scripts/perf/` |
| 测试数据生成 | 本仓 `scripts/data/` |
| 用例本体（编号 1~528+） | Kiwi TCMS 平台（不在 git） |
| 测试执行 | 各工程自带：`bms/backend/tests/`、前端 Vitest；由 CI 流水线驱动 |
